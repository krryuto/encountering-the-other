# Changelog

All notable public revisions to this repository are recorded here.

## v1.0 — 2026-09-07

Initial public release of the *Encountering the Other* research repository.

Includes:

- project README and methodological statement;
- Alignment Seed v1.0;
- 48 adversarial evaluation cases in machine-readable JSONL;
- contribution and red-team guidelines;
- provenance and contribution ledger;
- citation metadata;
- initial licensing and archival structure.

The Alignment Seed is derived from the Third Revision of *A Philosophy of Encountering the Other* (2026-09-07), which preserves earlier attributed contributions from Claude (Sonnet 5), GPT-5.6 Sol, and Astra.
